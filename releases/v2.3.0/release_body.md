# Muse v2.3.0

一次以"长任务体验"为核心的修复版：工具循环不再被轮次上限卡断，工具轮次密集时的上下文连续性问题根治（不再"失忆"），并修复记忆系统会清空数据的严重缺陷。建议所有用户升级。

## 重要修复

- **记忆不再丢失（严重缺陷）**：修复了数据库版本守卫写死导致的"每次启动清空事实记忆"问题；此前被误归档的数据如存在于备份中，升级后会自动找回一次。今后记忆不会再随启动丢失。
- **长工具任务不再"失忆"**：工具轮次密集时，更早的对话不再被静默截断——现在会生成可读的历史摘录（保留你与助手的原话），模型在长任务后仍记得之前聊过什么。
- **工具轮次放开**：默认不限轮次（可设 100 / 50 / 25），复杂任务一次做完；死循环保护仍然生效。

## 新能力

- **工具权限分层**：需要 Shizuku / Root、无障碍、Termux 的工具现在都有明确标注与就绪状态（`find_tools` 可查 READY / NOT READY），未授权时会立即返回明确错误，而不是"失败成谜"。
- **提示词技能支持参数**：自定义提示词技能可被传入 input，指令模板支持 `{{input}}` / `{{args}}` 占位符。
- **MOOD 调试出口**：logcat 可查 mood 提取详情。
- **知识库搜索**：相关度评分连续化，阈值参数真正可调；未命中会附诊断信息。

## 体验与修复

- 消息渠道卡片重布局：长名称 / 长账号 ID 不再挤成竖排，操作按钮独立成行。
- 闹钟 / 倒计时：补齐系统权限声明（此前被系统拦截）；失败时明确报错。
- 压缩上下文调用加超时护栏，消除偶发的"首字等待半分钟"。
- 内置技能 schema 升级机制修复（升级后模型能看到最新参数）。
- ktlint 全量格式化清理。

## 安装

- Android 8.0+；同签名覆盖安装即可（2.2.0 / 2.2.1 用户直接升级）；调试包需先卸载。
